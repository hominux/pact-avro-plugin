Pact plugin for testing messages serialised by https://avro.apache.org/docs[Apache Avro] using the https://docs.pact.io[Pact] contract testing framework.
____

== Installation

Install the latest release into your Pact plugin directory:

[source,shell]
----
curl -fsSL https://github.com/hominux/pact-avro-plugin/releases/latest/download/install-plugin.sh | sh
----

Binaries exist for Linux, macOS and Windows on x86_64 and aarch64. See the
link:docs/modules/ROOT/pages/getting_started.adoc[getting started guide] for the Pact CLI install and platform requirements.
